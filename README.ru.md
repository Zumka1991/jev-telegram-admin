# Jev Telegram Guard

AI-модератор для Telegram-групп. Бот читает сообщения и с помощью модели
**Jev** (TypeSafe System One через OpenRouter) определяет нарушения и сам
принимает меры — удаляет сообщение, выдаёт мут или бан — по настройкам чата.

[English version](README.md)

📖 **Пошаговый мануал по запуску: [Setup Guide (English)](docs/SETUP.md).**

## Возможности

- **Категории**: мат, оскорбления, мошенничество/фишинг, буллинг, троллинг,
  спам (включая массовые «предложения работы» и рекрутинг-разводы) и флуд.
- **Решения от ИИ**: Jev — модель структурированных решений, а не чат-модель.
  Она отдаёт калиброванные вероятности и **рекомендованное наказание** с
  длительностью мута, поэтому наказание тоже может выбирать модель.
- **Умные эвристики спама**: одинаковый текст, разосланный по многим чатам, и
  посты с обилием ссылок/контактов повышают оценку спама.
- **Полное покрытие сообщений**: текст, подписи к медиа и отредактированные
  сообщения; стикеры и медиа учитываются антифлудом, а фотоальбом — как одно
  событие.
- **Сложные отправители**: сообщения других ботов, каналов и анонимных админов
  не обходят проверку; если такого отправителя нельзя мутить, бот удаляет
  нарушающее сообщение.
- **Настройка по каждому чату**: для каждой категории — `off`, `auto`, `warn`,
  `delete`, `mute` или `ban`; пороги, лимит предупреждений, длительность мута.
- **Мультиязычный интерфейс**: английский, русский, испанский, португальский,
  арабский.
- **Локализованное меню команд** Telegram под язык пользователя.
- **Хранение в SQLite**: настройки, нарушения, статистика участников.
- **Резервный режим**: если ключ OpenRouter не задан, работает простой движок
  на правилах.

## Как это работает

1. Сообщение отправляется в **Jev Decisions API** вместо чат-комплишена. Jev
   отвечает на типизированные вопросы: вероятности «да/нет» (`noul`), выбор
   (`choice`) и оценку по шкале (`score`).
2. Бот запрашивает вероятность по каждой категории, тип спама, уровень
   опасности и **рекомендованное наказание** с длительностью мута.
3. Поверх работают эвристики: одинаковый текст в разных чатах и обилие ссылок
   повышают вероятность спама.
4. Результат сравнивается с порогом и настройками чата, затем применяется.
5. Всё сохраняется в SQLite: настройки чата, нарушения, статистика.

Повторно доставленный апдейт не приводит ко второму наказанию. При переводе
обычной группы в супергруппу бот переносит настройки и статистику на новый
Telegram `chat_id`.

## Быстрый старт (Docker)

```bash
cp .env.example .env
# укажите BOT_TOKEN и OPENROUTER_API_KEY
docker compose up -d --build
docker compose logs -f
```

## Быстрый старт (локально)

Нужен **Python 3.10+** (рекомендуется 3.12).

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # заполните ключи
python -m app.main
```

## Настройка

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Ключ OpenRouter: https://openrouter.ai/keys
3. Добавьте бота в группу и выдайте права:
   - **Удалять сообщения**
   - **Ограничивать участников**

> **Важно:** у новых ботов включён *privacy mode*, поэтому в обычных группах
> они получают только команды и ответы. Отключите его у BotFather
> (`/setprivacy` → выбрать бота → **Disable**) или назначьте бота админом.
> См. [Диагностику](#диагностика).

### Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | токен Telegram-бота | — |
| `OPENROUTER_API_KEY` | ключ OpenRouter | — |
| `JEV_MODEL` | id модели Jev | `~typesafe/jev-latest` |
| `JEV_ENDPOINT` | эндпоинт Decisions API | `https://openrouter.ai/api/alpha/decisions` |
| `DATABASE_URL` | строка подключения к БД | `sqlite+aiosqlite:///./data/jev.db` |
| `DEFAULT_THRESHOLD` | порог уверенности модели | `0.55` |
| `DEFAULT_WARN_LIMIT` | предупреждений до бана | `3` |
| `DEFAULT_MUTE_MINUTES` | длительность мута | `60` |
| `DEFAULT_LANGUAGE` | язык интерфейса по умолчанию | `en` |

## Команды

| Команда | Действие |
|---|---|
| `/settings` | меню настроек чата (инлайн-кнопки) |
| `/stats` | статистика нарушений за 7 дней |
| `/check <текст>` | проверить текст без действий |
| `/warn` | предупредить (ответом на сообщение) |
| `/unwarn` | снять предупреждения (ответом) |
| `/resetwarns` | сбросить предупреждения (ответом) |
| `/help` | справка |

## Настройки чата

В `/settings` для каждой категории выбирается действие:

- `off` — не реагировать;
- `auto` — **бот сам решает** (удалить / мут / бан) по опасности и
  рекомендации Jev;
- `warn` — предупредить (по достижении лимита — бан);
- `delete` — удалить сообщение;
- `mute` — замутить;
- `ban` — забанить.

Также настраиваются порог уверенности, лимит предупреждений, длительность
мута, игнорирование админов, уведомления и язык интерфейса.

## Языки

Интерфейс поставляется с пятью языками и переключается для каждого чата через
`/settings` → 🌐 **Язык**:

| Код | Язык |
|---|---|
| `en` | English |
| `ru` | Русский |
| `es` | Español |
| `pt` | Português |
| `ar` | العربية |

Переводы лежат в `app/i18n/locales/<код>.py` как плоский словарь `STRINGS`.
Чтобы добавить язык: скопируйте `en.py`, переведите значения, зарегистрируйте
локаль в `app/i18n/__init__.py` (`LOCALES`, `LANGUAGE_ORDER`, `LANGUAGE_NAMES`,
`LANGUAGE_FLAGS`) и добавьте значение колонки `language`. Английский —
фолбэк для отсутствующих ключей.

## База данных

SQLite через `aiosqlite`. Файл по умолчанию — `./data/jev.db`, в Docker
монтируется как `./data:/app/data`. Переход на PostgreSQL: задайте
`DATABASE_URL` вида `postgresql+asyncpg://…` и добавьте `asyncpg` в
`requirements.txt`.

Аддитивные миграции SQLite выполняются при старте, поэтому новые колонки
добавляются в уже существующую базу автоматически.

## Диагностика

**Бот не реагирует на сообщения.**

1. **Privacy mode.** В обычных группах бот получает только команды, ответы и
   упоминания, пока privacy mode включён. Отключите его у BotFather
   (`/setprivacy` → бот → **Disable**) или сделайте бота админом. Бот логирует
   каждое полученное сообщение: запустите `docker compose logs -f` и напишите
   в группу — если в логах пусто, дело в privacy mode.
2. **Игнорирование админов.** По умолчанию включено «Игнорировать админов»,
   поэтому сообщения администраторов пропускаются. Отключите в
   `/settings` → ⚙️ Параметры или проверяйте с неадминского аккаунта.
3. **Нет прав.** Боту нужны *Удалять сообщения* и *Ограничивать участников*.
   Проверьте в `/settings` → 🩺 Проверить права бота.
4. **Модерация выключена.** Убедитесь, что модерация включена в `/settings`.

**`/check` показывает низкие вероятности.** Снизьте порог в
`/settings` → ⚙️ Параметры или выберите действие, отличное от `off`.

## Безопасность

- `.env` в `.gitignore` — не коммитьте ключи.
- Бот хранит только короткие фрагменты сообщений (до 500 символов) и
  идентификаторы, необходимые для статистики.
- Выдавайте боту минимум прав: удаление сообщений и ограничение участников.
